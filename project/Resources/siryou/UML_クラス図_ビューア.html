エネミー行動制御のUMLクラス図 (State Pattern & ポリモーフィズム)

※学校の提出要件（継承・コンポジション・依存の専用記号）を網羅した本命のクラス図です 
classDiagram
    direction TB

    class GameObject {
        #Vector3 position_
        #Vector3 rotation_
        #Vector3 scale_
        +Initialize()*
        +Update(deltaTime)*
        +Draw()*
    }

    class BoxCollider {
        +bool hasCollider
        +Vector3 center
        +Vector3 size
    }

    class Enemy {
        -float hp_
        -float radius_
        -BoxCollider collider_
        -unique_ptr~IEnemyState~ currentState_
        +Initialize(position, hp, radius)
        +OnUpdate(deltaTime)
        +ChangeState(newState)
        +TakeDamage(damage)
    }

    class IEnemyState {
        <>
        +Enter(enemy)*
        +Update(enemy, deltaTime)*
        +Exit(enemy)*
    }

    class EnemyStateSideWait {
        +Enter(enemy)
        +Update(enemy, deltaTime)
    }

    class EnemyStateAppear {
        +Enter(enemy)
        +Update(enemy, deltaTime)
    }

    class EnemyStateWander {
        +Enter(enemy)
        +Update(enemy, deltaTime)
    }

    class EnemyStateDive {
        +Enter(enemy)
        +Update(enemy, deltaTime)
    }

    class EnemyFactory {
        +CreateEnemy(position, hp, radius)$ Enemy
    }

    %% 継承関係 (三角形矢印: extends)
    GameObject <|-- Enemy : 継承 (extends)
    IEnemyState <|-- EnemyStateSideWait : 実装 (implements)
    IEnemyState <|-- EnemyStateAppear : 実装 (implements)
    IEnemyState <|-- EnemyStateWander : 実装 (implements)
    IEnemyState <|-- EnemyStateDive : 実装 (implements)

    %% コンポジション (黒い塗りつぶし菱形: 強い所有 / 値メンバ・unique_ptr)
    Enemy *-- BoxCollider : コンポジション (値所有)
    Enemy *-- IEnemyState : コンポジション (排他所有)

    %% 依存関係 (破線矢印: 引数による一時参照 / Factoryによる生成)
    IEnemyState ..> Enemy : 引数で一時参照 (depends)
    EnemyFactory ..> Enemy : 生成して返却 (creates)

記号と設計の対応解説

  • 継承（<|--）: GameObject を継承して Enemy が派生。また IEnemyState を継承して各行動状態（SideWait, Appear, Wander, Dive）をポリモーフィズムで定義。
  • コンポジション（*--）: Enemy はコリジョン BoxCollider を値型で持ち、状態インスタンス currentState_ を std::unique_ptr で強く所有。
  • 依存（..>）: IEnemyState::Update が引数として Enemy* を受け取る一時的な参照、および EnemyFactory が Enemy を生成して返す関係。

シーン管理のUMLクラス図 (Abstract Factory & 集約・コンポジション)

※集約（白菱形）とコンポジション（黒菱形）の両方の使い分けを明確にアピールできるクラス図です 
classDiagram
    direction TB

    class AbstractSceneFactory {
        <>
        +CreateScene(sceneName)* unique_ptr~BaseScene~
    }

    class SceneFactory {
        +CreateScene(sceneName) unique_ptr~BaseScene~
    }

    class BaseScene {
        <>
        +Initialize()*
        +Finalize()*
        +Update()*
        +Draw()*
    }

    class TitleScene {
        +Initialize()
        +Update()
        +Draw()
    }

    class GamePlayScene {
        +Initialize()
        +Update()
        +Draw()
    }

    class ClearScene {
        +Initialize()
        +Update()
        +Draw()
    }

    class GameOverScene {
        +Initialize()
        +Update()
        +Draw()
    }

    class SceneManager {
        -unique_ptr~BaseScene~ currentScene_
        -AbstractSceneFactory* sceneFactory_
        +GetInstance()$ SceneManager*
        +ChangeScene(sceneName)
        +SetFactory(factory)
        +Update()
        +Draw()
    }

    %% 継承関係
    AbstractSceneFactory <|-- SceneFactory : 継承 (extends)
    BaseScene <|-- TitleScene : 継承 (extends)
    BaseScene <|-- GamePlayScene : 継承 (extends)
    BaseScene <|-- ClearScene : 継承 (extends)
    BaseScene <|-- GameOverScene : 継承 (extends)

    %% コンポジション (黒い菱形: 強い所有)
    SceneManager *-- BaseScene : コンポジション (unique_ptr所有)

    %% 集約 (白い菱形: 弱い所有 / 外部ポインタ注入)
    SceneManager o-- AbstractSceneFactory : 集約 (ポインタ参照)

    %% 依存関係
    SceneFactory ..> BaseScene : 生成 (creates)

集約とコンポジションの使い分け

  • 集約（o--）: SceneManager は工場 AbstractSceneFactory の所有権を持たず、ポインタを外部から受け取って参照しているだけ（寿命が連動しない）のため「集約」です。
  • コンポジション（*--）: シーン実体 currentScene_ は SceneManager が unique_ptr で寿命を一元管理するため「コンポジション」です。
